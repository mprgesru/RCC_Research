# Example Interpretation Chips

Six examples from the 2020 reference sample, committed so the images can be viewed
directly in the repository. Full sets are in the
[`chips-2020-v1` release](https://github.com/mprgesru/RCC_Research/releases/tag/chips-2020-v1).

| File | Season | Sample | What it shows |
| --- | --- | --- | --- |
| `BORO_S2020-0428.png` | Boro | S2020-0428 | Clear water (Padma); the map also says water |
| `BORO_S2020-0001.png` | Boro | S2020-0001 | Dense homestead vegetation; the map says Boro rice, so this is a visible false positive |
| `BORO_S2020-0041.png` | Boro | S2020-0041 | Mixed peri-urban fields and trees |
| `AMAN_S2020-0001.png` | Aman | S2020-0001 | Same point, monsoon date |
| `AMAN_S2020-0041.png` | Aman | S2020-0041 | Same point, monsoon date |
| `AUS_S2020-0428.png` | Aus | S2020-0428 | Same water point, Aus date |

Each image has three panels: true colour, false colour (NIR-R-G) and NDVI. Titles
omit the mapped class so interpretation stays independent.
